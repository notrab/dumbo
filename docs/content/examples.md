# Examples

Forty-odd little apps, each doing one thing well. Steal freely. 🐘

Every folder in the [examples directory](https://github.com/notrab/dumbo/tree/main/examples) is a small, runnable Dumbo app. Each one has its own `composer.json`, so you can `cd` in, run `composer install` and `composer start`.
